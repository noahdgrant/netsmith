# A process is a generic, and each copper weight is a provider

The mechanism is the owner's decision of 2026-11-13 (issue #431, S1b, option 1 of the comment of 2026-11-11). The two rules it needed that the decision did not state, the search opening on a contradiction and the lock holding a provider, are the agent's under the owner's delegation of 2026-11-11, and the owner has not seen this text. It meets two of the three tests: it is hard to reverse (std's process becomes a generic, and lock files gain a table) and it rejects obvious alternatives (a table of process rows; one interface per weight).

**Decision.** A board writes the copper weight as a field, `.process: TwoLayer { .stackup.copper_weight &= 2 }`, and the rules that depend on it follow. JLCPCB's figures by weight follow no formula, so each weight is its own definition: `TwoLayer` is a `generic` that declares every field and states what holds at every weight, and `interface JlcTwoLayer1oz provides TwoLayer` and `JlcTwoLayer2oz` state the track, space, annular ring, mask bridge and weight, each with its source. ADR 0068's machinery picks one, so the pick needs nothing new in the router, the check or the current rating: each reads the `Process` the design stage builds from whichever provider stands.

- **An interface provides a generic** that has no `pins` table and no catalog. All the providers of a generic are parts, all are modules, or all are interfaces, and a use is made as the kind they are. An interface cannot provide a generic with pins.
- **A contradiction inside a varied use opens the search.** A provider's `&= 1` against the board's `&= 2` is found by the checker, not the solver, and ADR 0068 starts the choice only after a clean check. Now a contradiction on a field inside a use with more than one provider in scope is kept apart (`Model::provider_conflicts`); when every mistake of the check is one, the build tries the other providers as it does for a failed solve, and a board whose weight no provider has gets ADR 0068's error naming each. Any other mistake of the check still stops the build before any pick.
- **The pick lock records the provider** of each use with more than one provider in scope (`[Board.providers."process"]`, its generic and the provider's id), and holds the use to it as it holds a part to its row (ADR 0100): the use is never varied, a weight the locked provider does not have stops the build with a note naming the lock, and a locked provider no longer in scope is an error. `lock --update` picks again and prints the change.
- **The name of the process** in the design (`Process::name`, `fab-notes.txt`) is the type the board wrote, `TwoLayer`, not the provider's: the weight is already in that line, and a board that states no weight is made byte for byte as before. An interface provider taken first with nothing passed over prints no note, or every board would print its default weight.
- **Only the weights the page gives every rule for have a provider.** JLCPCB's page gives 2.5, 3.5 and 4.5 oz track and space but no annular ring or mask bridge; a process states every rule (issue #431), and a lighter weight's figure would be too small, so they have none. The page gives multilayer 2 oz rules but its impedance page lists no build-up with 2 oz outer copper, so `FourLayer` and `SixLayer` stay 1 oz interfaces.

**Rejected: a table of process rows** (`data/jlcpcb/processes.csv`, one row per weight, read like a catalog). A new kind of catalog, and the numbers would leave std, where their sources sit beside them. **Rejected: one interface per weight with no language change** (`.process: TwoLayer2oz`). The board would name the weight in the type, which the owner did not choose. **Rejected: a field whose rules are a function of another field.** The language has no such construct, and the figures follow no formula. **Rejected: opening the search on any check failure** (ADR 0068 rejected it, and the reason holds: a provider's own mistake would move the pick). **Rejected: a filter in the checker that drops a provider whose statements contradict the use** before any trial: a second place that judges providers, and its reasons would not reach the error that names each.

**Cost.** A board that states a weight costs one more check per provider passed over, a few milliseconds. Every lock of a board on `TwoLayer` gains a provider entry, once. A contradiction inside a use with several providers, such as a module provider's value against the board's, is now judged by trying the others, which can change which provider a board with such a mistake ends on: the error then names each, as before. A provider's id (`std::mfg::jlcpcb::JlcTwoLayer1oz`) in a lock changes if the definition moves.

**Left open.** Providers for 2.5, 3.5 and 4.5 oz once JLCPCB states their annular ring and mask bridge, and 2 oz multilayer once it lists a build-up. Inner copper weight on multilayer boards.
