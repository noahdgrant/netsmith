netsmith symbol gallery

Every symbol netsmith draws itself (ADR 0097), beside the KiCad symbol it replaces, at one scale and in one frame. Left, netsmith's drawing; right, KiCad 9's stock symbol of the id the mapping names. Pin numbers are red, pin names teal, the pin's connection point is a dot, and the Reference and Value fields are where each symbol puts them.

This page is generated: cargo run -p netsmith --example symbol_gallery -- --out docs --file symbol-gallery.html. Do not edit it.

KiCad's symbol library: found when this page was written; each stock symbol is drawn from it.

ICs drawn from a pin table

A part with no symbol of its own is drawn as a box from its pin table (generate.rs): power in and ground on the left, power out on the right, the rest in pin order. These are the pin tables of four parts of examples/. netsmith's box is drawn as a sheet shows the part, with the part's own value under it (the library's name for the symbol, which says the package, is not shown).

The stock symbols are drawings of KiCad's symbol libraries, © the KiCad Library Team, CC-BY-SA 4.0 (with the exception for designs that use them); netsmith's own symbols are drawn from the electrical and mechanical conventions, not from KiCad's files. What the page does not draw: pin graphic styles (an inverted or clocked pin is a plain line), overbars of ~{NAME}, hidden pins and fields, units after the first, and a text's font.
